# 🚀 Stock Analyzer V2 - Quick Start

## Installation (Choose One)

### Option 1: **From ZIP (Easiest)**
```bash
1. Download: Stock-Analyzer-V2-Portable.zip (157 MB)
2. Extract anywhere (USB, local folder, etc.)
3. Run: Stock Analyzer V2.exe
```

### Option 2: **From Folder**
```bash
1. Copy: Stock-Analyzer-Portable/ folder to USB
2. Navigate to folder on any Windows machine
3. Run: Stock Analyzer V2.exe
```

### Option 3: **Build from Source**
```bash
npm install
npm run build
npm run electron
```

## First Steps

1. **Launch** `Stock Analyzer V2.exe`
2. **Create Portfolio** - Add your stocks
3. **View Analysis** - See charts and metrics
4. **Add Watchlist** - Track stocks you're interested in
5. **Configure AI** (Optional) - Add Gemini API key for insights

## ✨ Key Features

- 📊 Real-time stock data

- 📈 Interactive charts
